GB1: measurement noise, estimated two independent ways
====================================================================================================
  the viable pool: n=11522  mean 0.962  sd 1.087
  a campaign's champion sits near fitness 4.997 (median of the pool's top 200)

  METHOD 1. Poisson read-sampling noise, from the published depth.
  Var(log w) = 1/n_sel + 1/n_in (+ WT terms, negligible: WT is abundant).
    average depth: 557 input, 285 selected reads per variant
    Var(log w) = 1/285 + 1/557 = 0.005306   ->  CV = 7.3%
    noise is MULTIPLICATIVE: sigma_linear(f) = f x CV, which is the
    heteroscedasticity FLIGHTED reports. At the champion level f=5.00:
      sigma = 0.364 fitness units
    ADVERSARIAL BOUND: a variant at the read-count filter (n_in = n_sel = 10)
      CV = 44.7%  ->  sigma = 2.235 at the champion level
      but such variants are the WORST-sampled 6.6%% that barely passed the filter,
      and an enriched high-fitness variant is by definition well sampled after
      selection, so this is an upper extreme and not the champion's regime.

  METHOD 2. From the published replicate agreement, Pearson r = 0.97.
  For X1 = T + e1 and X2 = T + e2 with equal error variance,
  r = var(T)/(var(T)+var(e)), so sd(e) = sd(T) x sqrt((1-r)/r).
    sd(e) = 0.176 x sd(T) = 0.176 x 1.087 = 0.191 fitness units
    NOTE THIS IS GENEROUS TO THE PAPER: r=0.97 was reported for SINGLE AND DOUBLE
    mutants, which are the best-sampled variants, so the true landscape-wide
    correlation is LOWER and the implied noise HIGHER. Using the pool's sd as sd(T)
    rather than the subset's also inflates the estimate.

----------------------------------------------------------------------------------------------------
  WHERE REAL GB1 SITS ON THE RATIO AXIS
----------------------------------------------------------------------------------------------------
   in the inherited-calibrated unit (sigma_unit = 0.420):
     Poisson, average depth                 sigma  0.364  ->  ratio  0.87
     replicate correlation r=0.97           sigma  0.191  ->  ratio  0.46
     Poisson, worst variant at the filter   sigma  2.235  ->  ratio  5.32
   in the random-calibrated unit (sigma_unit = 0.557):
     Poisson, average depth                 sigma  0.364  ->  ratio  0.65
     replicate correlation r=0.97           sigma  0.191  ->  ratio  0.34
     Poisson, worst variant at the filter   sigma  2.235  ->  ratio  4.01

   HOW MUCH WOULD HAVE TO BE WRONG for real GB1 to reach ratio 4.0?
     ratio 4.0 in the random-calibrated unit needs sigma = 2.228
     that is 6.1x the Poisson estimate and 11.7x the replicate estimate.
     By Method 1 it needs CV = 45%, i.e. effective depth of about 10 reads
     per variant against the published ~285-557.
     By Method 2 it needs replicate r = 0.192 against the published 0.97.

PhoQ: no replicate data located, and a separate problem
====================================================================================================
  Podgornaia & Laub report 1,659 FUNCTIONAL variants of 160,000 (1.04%).
  Our viable pool, threshold > 1.0, holds 11146 (6.97%), which is 6.7x more.
  The 1,659th highest value in our file is 14.183, so the published functional call
  corresponds to a threshold near 14.2 in these units, not 1.0.
  CONSEQUENCE: the design space the whole experiment restricts to is NOT the
  published functional set. That is a methods problem independent of the noise
  question, and it changes pool size, sigma unit and every ratio.

  Their assay was a TWO-STEP selection with a binary functional call, so it
  publishes no per-variant noise to anchor against. No PhoQ anchor is available
  from this source, and I am not going to manufacture one.
